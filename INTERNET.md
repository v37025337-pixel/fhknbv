# Реальный интернет в 0.3.1

Модуль `digital_mind_core.internet` получает публичные HTTP(S)-ресурсы через настоящий сетевой транспорт Python. В подключённой среде он использует её штатный прокси и проверку TLS. HTML преобразуется в текст; JSON API дополнительно преобразуются в ограниченный набор полей. Содержание, адрес, время получения и SHA-256 ответа входят в наблюдение того же когнитивного ядра, которое обрабатывает остальные задачи.

Доступ включён явно для работающего экземпляра. Создание обычного `MindModule()` или чтение `status` не выполняет сетевых запросов.

## Запуск

```bash
python -m digital_mind_core.tool_module --internet --web-memory web_memory.json
# Или обёртка для вызовов вокруг работы модели:
python -m digital_mind_core.model_plugin --internet --web-memory web_memory.json
```

Родительская папка файла памяти должна существовать. Процесс принимает по одному JSON-запросу на строку:

```json
{"op":"internet_status"}
{"op":"fetch_url","url":"https://example.com/"}
{"op":"fetch_url","url":"https://api.github.com/repos/v37025337-pixel/fhknbv"}
{"op":"web_memory"}
```

`fetch_url` возвращает `source` с текстом и происхождением, результат регистрации в ядре и признак сохранения памяти. При ошибке сети запрос получает `ok:false`, а процесс продолжает принимать запросы. Успешное получение URL выполняется по запросу; фонового бесконечного обхода сайтов нет.

Для повторного использования данных передайте полученный `source.id`:

```python
from digital_mind_core.internet import WebReader
from digital_mind_core.tool_module import MindModule

core = MindModule(web_reader=WebReader(), web_memory_path="web_memory.json")
loaded = core.execute({"op": "fetch_url", "url": "https://api.github.com/repos/v37025337-pixel/fhknbv"})
source_id = loaded["source"]["id"]
answer = core.execute({"op": "reason", "web_source_id": source_id, "task": {
    "queries": [["web_field", source_id, "full_name", "v37025337-pixel/fhknbv"]]
}})
assert answer["inferences"][0]["value"]
```

`web_memory` с `source_id` возвращает полное сохранённое наблюдение. Без него возвращаются метаданные последних 16 источников. При повторном запуске с тем же файлом источники восстанавливаются без сетевого запроса; `reason` с `web_source_id` снова передаёт выбранный источник в обработку ядру. JSON-поля обозначают то, что сообщил источник, а не независимо установленные факты о мире.

## Границы данных

Каждое наблюдение помечено `unverified_external_data`. Текст страницы не превращается в правила, инструменты или исполняемый код. Для JSON фиксируются до 48 скалярных значений с именами полей; правила и запросы задаёт вызывающее приложение. В этой версии нет языковой модели, автоматического понимания произвольных текстов, поискового сервиса или самостоятельного исследования всего интернета.

Поддерживаются HTML, текст, JSON и текстовые XML-ответы, в том числе gzip и deflate. Динамические страницы, требующие JavaScript, входа в аккаунт или CAPTCHA, могут не дать полезного текста. Ответы Brotli и двоичные файлы отклоняются. Один ответ ограничен 256 КиБ как при получении, так и после распаковки; сохраняемый текст — 12 000 символами. Превышение лимита байтов отклоняет ответ, сокращение текста явно отмечается `truncated`. Для сетевого сокета установлен таймаут 10 секунд; это не обещание общего времени запроса с DNS и перенаправлениями.

Поддерживаются GET-запросы без пользовательских заголовков и cookie-сессий; URL с логином и паролем отклоняются. Адреса localhost, локальные IP и DNS-ответы с непубличными адресами отклоняются, в том числе при перенаправлениях. Число перенаправлений ограничено. Стандартный прокси среды сохраняется; проверки адресов не заменяют сетевую политику этого прокси.

Память веб-источников — отдельный JSON-файл. Replay искусственного мира не включает внешние сетевые наблюдения; после них используется отдельная память источников и сохранение механизмов. Получение текста не обучает числовую прогнозную модель искусственного мира: данные пополняют внешние наблюдения и используются в символических задачах.

## Проверка

```bash
python -m unittest discover -s tests -p test_internet.py -v
python tools/verify_internet_live.py --report examples/internet_live_report.json --memory web_memory.json
```

Первый набор проверок работает без интернета и покрывает транспорт, обработку HTML/JSON, ограничения, сетевые ошибки, перенаправления, память и интеграцию с ядром. Второй выполняет настоящие GET-запросы к Example.com, Python.org и GitHub API, проверяет регистрацию наблюдений, логический запрос по JSON-данным и восстановление памяти. Этот сетевой сценарий выполняется отдельно от CI, поскольку доступность внешних сайтов меняется.

Прогнозные результаты 2.45% в `LEARNING.md` относятся к исследованию 0.3.0; они не являются доказательством обучения на веб-текстах в 0.3.1.
